# Проект: Графический интерфейс пользователя
**Цель проекта** - научиться работать с графическими интерфейсами и создать 3 учебных проекта: кулькулятор, форму учёта-отчёта и приложение для чтения FASTQ-файлов
## Описание проекта
В репозитории представлены решения трёх заданий:
1.  **Калькулятор** (GUI с валидацией и обработкой ошибок).
2.  **Формы учёта-отчёта** (GUI для работы с данными пациентов и статистикой).
3.  **Урезанный FastQC** (GUI для анализа файлов FASTQ).

## Инструкция к запуску
Для демонстрации проекта необходимо выполнить следующие шаги в командной строке:

### 1. Клонирование репозитория
Скачайте проект на свой компьютер:
  
  `git clone https://github.com/cybernytik/gui_projects`
  
  `cd gui_projects`

### 2. Создание и активация виртуального окружения
Создайте окружение:

  `python3 -m venv .venv`

Активируйте:

  `source .venv/bin/activate`
  
### 3. Установка зависимостей
  
  `python -m pip install -r requirements.txt`

### 4. Запуск приложений
- **Калькулятор:**
  ``` bash
  python task_calculator/main.py

- **Форма учета-отчета:**
  ``` bash
  python task_calculator/main.py

- **FastQC:**
  ``` bash
  python task_calculator/main.py

### 5. Завершение работы с виртуальным окружением и его удаление

  `deactivate`

  `rm -rf .venv`

## Структура репозитория
- `task_calculator/` — исходный код калькулятора.

- `task_patients/` — код для формы пациентов и построения графиков.

- `task_fastqc/` — код для работы с FASTQ и визуализации.

- `requirements.txt` — список зависимостей
